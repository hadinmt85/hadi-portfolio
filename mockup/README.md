# Mockup — hadinemati.ir

طرح پیشنهادی برای بازطراحی سایت شخصی، بر اساس اصول
[emilkowalski/skills](https://github.com/emilkowalski/skills) (به‌ویژه `emil-design-eng`).

فایل `index.html` کاملاً مستقل است؛ برای دیدنش کافی است در مرورگر باز شود:

```bash
start mockup/index.html   # ویندوز
```

## چه چیزی در طراحی رعایت شده

- **سکوت بصری:** بدون گرادیان نئونی، گلَس و هاله. فقط یک رنگ تأکید (سبز) در نقاطی که معنا دارد.
- **سلسله‌مراتب:** نام بزرگ، متن دوم، جزئیات سوم؛ پروژه‌ها به‌جای کارت، لیست ردیفی.
- **حرکت:** فقط ورودِ کوتاه (اوپسیتی + ۱۰px)، ۵۲۰ms با `cubic-bezier(.23,1,.32,1)`؛ هاور ردیف‌ها ۲۰۰ms؛ دکمه‌ها `:active` با `scale(.97)`.
- **بدون انیمیشن روی حرکات پرتکرار** و احترام به `prefers-reduced-motion`.
- **هاور فقط روی دستگاه‌های دقیق** (`@media (hover: none)` برای خنثی‌کردن).
- **دو تم و دو زبان** با ذخیرهٔ انتخاب کاربر، و تشخیص خودکار تم سیستم.

> این یک ماکاپ استاتیک است (HTML/CSS/JS خالص) و به کد اصلی Next.js وصل نیست.
