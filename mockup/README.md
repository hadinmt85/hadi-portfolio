# Mockup — hadinemati.ir

دو طرح پیشنهادی برای سایت شخصی، بر اساس اصول
[emilkowalski/skills](https://github.com/emilkowalski/skills) (به‌ویژه `emil-design-eng`).

| فایل | توضیح |
| --- | --- |
| `index.html` | نسخهٔ ۱ — مینیمال و تک‌صفحه‌ای (فقط برای مقایسه) |
| `v2.html` | نسخهٔ ۲ — تمام قابلیت‌های سایت فعلی + طراحی پرجزئیات‌تر |

`v2.html` یک فایل مستقل است؛ در مرورگر بازش کن:

```bash
start mockup/v2.html   # ویندوز
```

## قابلیت‌های پوشش‌داده‌شده در v2

- هدر چسبان با ناوبری فعال، منوی موبایل، تغییر زبان و تم
- هیرو با عکس پروفایل، کارت کد، برچسب‌های شناور و نوار تکنولوژی‌ها
- آمار، معرفی، سه کارت مهارت با نوارهای انیمیشنی
- سه پروژه با اسکرین‌شات واقعی و **پنجرهٔ مطالعهٔ پروژه** (مسئله/رویکرد/چالش/نتیجه + استک + CTA)
- تماس: کپی ایمیل، ارسال از Gmail، نمایش شمارهٔ ماسک‌شده، فرم با حالت‌های ارسال/موفقیت
- **پنجرهٔ رزومه** با نمایش PDF و دانلود
- تم روشن/تیره، فارسی/انگلیسی، احترام به `prefers-reduced-motion`
- تیلت ملایم کارت پروفایل فقط روی دستگاه‌های دقیق (hover/pointer: fine)

## اصول حرکتی

- ورود: `opacity` + `translateY(12px)`، ۶۰۰ms با `cubic-bezier(.23,1,.32,1)`، استگر ۶۰ms
- هاور کارت‌ها: ۳۰۰ms، فقط `transform`/`border-color`/`box-shadow`
- دکمه‌ها: `:active { scale(.97) }` در ۱۵۰ms
- پنجره‌ها: `translateY` + `opacity` در ۳۰۰ms با `cubic-bezier(.32,.72,0,1)`
- بدون انیمیشن روی حرکات پرتکرار؛ هاور فقط روی دستگاه‌های دقیق

> نکته: ارسال فرم در ماکاپ شبیه‌سازی شده است (API واقعی در سایت اصلی است). تصاویر از پوشهٔ
> `public/` خوانده می‌شوند، پس فایل را داخل همین ریپو نگه دار.
